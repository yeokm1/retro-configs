
 DOSX.exe: replaces the Win 3.1 SYSTEM\DOSX.EXE. Needed to make Win 3.1
   accept HDPMI16i as DPMI host.

 ShareA.exe: a Windows version of FakeShare; intended to make 16-bit
   MS Office programs not to complain about a missing SHARE.EXE. This tool
   does NOT implement the functionality that a true SHARE.EXE may supply.

 SetEnh.exe: switch between Windows 3.1 Standard Mode and (faked) Enhanced
   Mode.

 SetHost.exe: makes HDPMI16 hide itself in DOS boxes.
