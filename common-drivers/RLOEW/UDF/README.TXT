The Windows 95/95C UDF Filesystem allows Windows 95 to read UDF formatted
data from CD/DVD Disks. UDF Format extends the allowed File Names and Paths
over older Formats and is required on DVD Video Disks.



REQUIREMENTS

Windows 95, 95A, 95B or 95C.



CONTENTS

UDF95.VXD       UDF Filesystem Drive for Windows 95 and 95A
UDF95.BAT       Installation script for Windows 95 and 95A
UDF95C.VXD      UDF Filesystem Drive for Windows 95B and 95C
UDF95C.BAT      Installation script for Windows 95B and 95C
UDF.REG         Registry Update script
UNIN_UDF.BAT    Uninstall script
NOUDF.REG       Uninstall Registry Update script
README.TXT      This File
LICENSE.TXT     License terms and conditions



INSTALLATION

1. Unzip all files into a single folder.
2. CD to this filder.
3. If using Windows 95 or 95A, type the following Command:

UDF95

4. If using Windows 95B or 95C, type the following Command:

UDF95C

5. Reboot



UNINSTALL

1. Unzip all files into a single folder.
2. CD to this filder.
3. Type the following Command:

UNIN_UDF
